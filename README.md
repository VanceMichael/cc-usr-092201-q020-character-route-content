# 赛道汉字内容编排

维护汉字文化内容的来源、授权、赛道点位和发布版本。

## 资料范围

领域资料位于 `fixtures/domain.json`，结构约定见 `contracts/domain.schema.json`。当前记录类型包括汉字条目、来源材料、图像授权、点位载体、印刷批次、参与反馈，状态示例为待编写 → 专家审校 → 待授权 → 已发布 → 需更换 → 已归档。这些样例使用虚构标识，不含真实个人资料、账号或连接凭据。

已整理的业务事实：

- 赛事把汉字演变融入沿线展区和打卡点
- 内容引用多件文物的视觉素材
- 终点设置拓印和简牍书写等互动体验

## 本地校验

项目自带的测试会读取样例并检查领域标识、版本、记录类型、流程状态和事实说明。后续服务应继续兼容这份公开资料约定。
